# Contributing

- `main` is protected; do not push directly to `main`.
- Use `test-branch-front-edited-by-AI-authentication-code` as the shared integration branch for all recent feature and testing changes.
- Do not create separate feature branches for routine changes; keep the shared branch current and open a pull request from it to `main` when the work is ready.
- Keep pull requests small and focused.
- Request buddy review within 24 hours.
- Use conventional commits (example: `feat: add claim form scaffold`).
- Any schema, status lifecycle, or API contract change must be in a PR that tags all affected members.
